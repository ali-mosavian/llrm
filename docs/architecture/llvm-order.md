# LLVM's pass order: rows, traced causes and turn-on conditions

Evidence for PR #2164 (`Options::llvm_order`, `LLRM_EXP_LLVM`, off by default). References: rows/main24d (clang 24.0.0git d1106deb71cc, gcc 13.4.0).

TL;DR: LLVM's function-pipeline order (early FPM, GlobalCleanup, function simplification once per body) behind `Options::llvm_order` (`LLRM_EXP_LLVM`, off), with EarlyCSE translated from EarlyCSE.cpp in its two slots and the dead-slot step (`DeadSlots`: the alloca nothing loads goes with its stores, as PromoteMemToReg/SROA leave none) with the SROA/promote slots. Off, 1,587 of 1,587 objects are identical to main (`identical.py`, all levels, bench included). On, d_faces -O2 compiles in 8.0% fewer instructions (2,138 M → 1,968 M, before the dead-slot step; 1,999 M with it) and gvn/dse/algebraic run 12 times where main runs 34-35. Without the dead-slot step it loses the recursion family (the frame slots stay and `tailrec` refuses them); with it, 5 or fewer rows are worse per metric at -O1/-O2/-O3 and 7/6/4/6 at -Os, every one traced below. It lands off; CI runs the pipeline tests with the option on.

**Compile** (d_faces, dist build, `CARGO_INCREMENTAL=0`, fresh target per SHA, `-m32 -march=i486`, instructions:u): -O2 main 2,138 M, off 2,139 M, on 1,968 M (−8.0%; with dead slots 1,999 M); -Os main 2,240 M, on 1,995 M (−10.9%); -O1 main 1,695 M, on 1,834 M (+8.2%: -O1 reuses the -O2 list; LLVM's -O1 list is lighter, the mirror of it is a separate re-test item, not here). Pass runs on d_faces -O2 (11 bodies): gvn 35 → 12, dse 34 → 12, algebraic 34 → 12, earlycse 0 → 23; `decide` 35 → 82, `phiopt` 35 → 70, `fold` 36 → 59, `dead` 34 → 59 (decide: 78,962 runs over the full C corpus against 33,932; the runs go away when SimplifyCFG (simplifycfg-port), SCCP and CVP take decide's decisions at LLVM's slots).

**Rows above min(gcc, clang) moved** (references of record; main → stacked): clocks -O1 30→30, -O2 32→33 (x_hanoi2 newly above), -O3 28→27, -Os 39→41 (matmul, x_life, x_transpose newly above); ins -O1 48→48, -O2 48→48 (x_hanoi2 newly above, bintree now below), -O3 46→47 (x_hanoi2), -Os 29→33 (matmul, x_dct, x_life, x_matmul_f, x_transpose); mem -O1 24→24, -O2 38→37, -O3 35→35, -Os 21→22 (x_dct, x_life); code -O1 24→24, -O2 29→29, -O3 39→39, -Os 20→21 (matmul).

**LLVM structure** (PassBuilderPipelines.cpp at d1106deb71cc): early function pipeline l.1178-1180, GlobalCleanup l.1241-1244, `buildFunctionSimplificationPipeline` l.630-837 (slot names carry the line, e.g. `gvn@787`); EarlyCSE.cpp: SimpleValue/CallValue/GEPValue L100-L551, `isSameMemGeneration` L1066, `isOperatingOnInvariantMemAt` L1105, `handleBranchCondition` L1126, `getMatchingValue` L1183, `overridingStores` L1288, `processNode` L1322, `run` L1758 (a permalink on each Rust function). `llvm_order()` is the table; `Fixed::linear` runs a list once, and a list that runs once may end where it began (EarlyCSE drops the LCSSA phis `lcssa` makes again).

**Partial mirror, slots missing** (LLVM O2 `-print-pipeline-passes`, pinned opt): stand-ins: SimplifyCFG/JumpThreading/CVP = `decide` (+`phiopt`), InstCombine/Reassociate = `fold`+`algebraic`, LICM = `hoist`+`loopmotion` (with the spill forecast), LoopIdiom = `fill`, mem2reg/SROA = leaf `Sroa` + write-through `Promote` as one slot, ADCE = `dead`, mldst-motion = `merge`. Empty: CGSCC bottom-up inline (the inline stage runs after all bodies, callers first), SCCP, BDCE, loop-instsimplify, loop-simplifycfg, dfa-jump-threading, loop-rotate (late on purpose), function-attrs per SCC, the late `loop-unroll` + `sroa<preserve-cfg>`. -O3 differs from -O2 by callsite-splitting, argpromotion, chr, non-trivial unswitch, `loop-unroll<O3>`; -Os is -O2 with optsize.

**EarlyCSE DEVIATE** (module header): no invariant.start, guards, masked or target intrinsics, memset forwarding, fences or atomics (MIR has none, or `fill` makes them later); `simplify_instruction` is a local stub with the signature of `llrm_mir::simplify::simplify_instruction` (fold-poc), to be replaced by it; flags always intersected, a load's non-shared metadata dropped; call attributes not intersected; a GEP's constant offset taken for byte GEPs only; MemorySSA built once from a snapshot, erasures at the end of the walk (the walk returns `PreservedAnalyses::none()`); `MemorySSA::clobbers` returns the set of nearest defs. difftest against `opt -passes='early-cse<memssa>'` (pinned 24.0.0git): 54 of 58 steps identical, the 4 differ by `getelementptr` 14, `load` 4, `sext` 2 and one each of zext/ashr/fptrunc/icmp/sitofp.

**Oracles with the switch ON** (`identical.py`'s oracle set, every `LLRM_CHECK_*`, 1,583 compiles; main with the switch off: 0 fail on 1,587): before #2151, 408 failed: 396 `LLRM_CHECK_CLOBBERS` (`Accesses::update` returned the stale structure; root cause found by memoryssa-port, fixed by #2151 — with it merged, 0) and 12 `LLRM_CHECK_COUNTED`. With #2151 merged, 25 fail: 24 `LLRM_CHECK_COUNTED` (induction.rs:707, stale `Counted`; qcport host, mdl, mod_tex, combat, triggers, snd_mix at -O1/-O2/-Os/-Omax; basicaa-port's family) and 1 `LLRM_CHECK_DATAFLOW` (qcport savegame -Omax: the backend's spillforward worklist and round-robin solutions differ on one fact in a 3-block cycle of `_savegame_load@3`; lir-cleanup-poc). These are cache-contract assertions, not observed miscompiles: tests/run/c passes 340/340 with the switch on. `LLRM_CHECK_ROUNDS` prints 'round 2 would change the body' for every list (a report, not a failure).

**Turn-on condition** (each cause row above names its owner; PR numbers where they exist: cache fixes #2151, #2157 COUNTED, #2158 call-effects class; the rest owner session until its PR exists). (1) The rows rule is clean at every level on `main24d` with the failed-row summary: the worse rows above recovered by regalloc S1/S2 (allocator order, tail-recursion argument reload, spill slots), the LICM translation without the forecast (hoist rows), the ShrinkWrap backend item, cgscc-poc (`ipa-cp`/`ipa-inline0`), the GVN port with MemDep and memoryssa-port (global-cell forwarding), fold-poc (canonical forms), MemCpyOpt/loopidiom-port (store merging, lru), LSR translation (x_list). (2) Every oracle silent with the switch ON (identical.py's set): #2151 merged, COUNTED (#2157, basicaa-port), the savegame `LLRM_CHECK_DATAFLOW` fix (lir-cleanup-poc), the call-effects class (#2158). (3) `decide` runs down by simplifycfg-port. Until then the switch stays off. **Coverage:** the 8 EarlyCSE tests plus 2 pipeline tests with the option on (stage count, one `gvn`/`dse`, the loop computes the same answer); the corpus never exercises EarlyCSE's memset/lifetime/atomic paths (MIR has none at its slots).
