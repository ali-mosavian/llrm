# Translating MachineCombiner (slot 40)

Pin d1106deb71cc, [`MachineCombiner.cpp`](https://github.com/llvm/llvm-project/blob/d1106deb71cc81016406a1917d0508d2df296266/llvm/lib/CodeGen/MachineCombiner.cpp). Plan only. Row 40 of [codegen-slot-table.md](codegen-slot-table.md); land 2026-11-06.

## The premise: a count, not a story
Pin ablation: changed code in 12 (-O2) and 6 (-Os) of 77 IRs. On i486 the only patterns are the generic reassociations (`X86InstrInfo::getMachineCombinerPatterns`, [L10982](https://github.com/llvm/llvm-project/blob/d1106deb71cc81016406a1917d0508d2df296266/llvm/lib/Target/X86/X86InstrInfo.cpp#L10982), adds the DPWSSD vector pattern, absent here, and defers to `TargetInstrInfo`): an associative and commutative `ADD/AND/OR/XOR/IMUL rr` ([L10174](https://github.com/llvm/llvm-project/blob/d1106deb71cc81016406a1917d0508d2df296266/llvm/lib/Target/X86/X86InstrInfo.cpp#L10174)) chain is rebuilt when the new tree shortens the critical path of its trace. There is no scheduling model for i486, so latencies are the defaults (`TargetSchedModel::computeInstrLatency` without a model).

## Data the pass needs that LIR does not have
- Trace depths: `analysis::intervals` gives block order and frequencies; a depth per vreg def over the trace (the block plus its single predecessor chain, as `MachineTraceMetrics`' `getEnsemble(MinInstrCount)` ... the strategy is `TS_MinInstrCount` for the generic case) is new. It is local to the pass until a second user exists.
- A per-instruction latency: the default (1 for ALU; `defaultDefLatency` for loads and high-latency ops); the i486 timings file (`crates/target/llrm-x86-m32/src/timings.times`) is a clock cost, not a pin latency, so the default table is written down in the pass with its source line.

## Deviations to record
- D1 (if used): no kill flags, no `MachineRegisterInfo` SSA: ours is pre-allocation SSA-like LIR; the single-use check (`hasOneNonDBGUse`) reads the vreg's use count.

## Tests
Fail first: a left-leaning chain of five adds whose last operand is loaded late is rebuilt balanced; one whose critical path would not shorten is left; an operand with two uses (the intermediate is used elsewhere) is left; non-associative ops (SUB) are left; `IMUL rr` chains follow the same rule.
