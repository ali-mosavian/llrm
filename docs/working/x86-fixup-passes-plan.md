## 48 X86 Fixup SetCC (land 11-02)
Pin: [X86FixupSetCC.cpp](https://github.com/llvm/llvm-project/blob/d1106deb71cc81016406a1917d0508d2df296266/llvm/lib/Target/X86/X86FixupSetCC.cpp#L68) `fixupSetCC`, one pass over blocks, SSA. Per block it remembers the latest instruction that defines EFLAGS (`FlagsDefMI`); for each `SETCCr` whose result has a `MOVZX32rr8` use, and with a flags def before it: unless that def also reads EFLAGS, constrain the zext's result to GR32_ABCD (32-bit) and insert `MOV32r0 -> vZero` BEFORE the flags def, then replace the zext by `INSERT_SUBREG vZero, vSetcc, sub_8bit`. `xor eax,eax; cmp; setl al` replaces `cmp; setl al; movzx eax,al`: no partial-register stall, one instruction shorter. (ZU variants: `hasZU` is APX, off.)
Ours: LIR after isel is `v3 := setl ; v4 := movzx v3` (ISEL_DUMP=1, `int f(int a,int b){return a<b;}`), pin llc gives `xorl %eax,%eax; cmpl; setl %al`. Hook: a `LIRTransform` `FixupSetCc` after `PressureSink` (slot `fixupsetcc@5`, with a registry row and `UNOPTIMIZED`: the pin skips it at -O0), before the float phases.
Open representation question (step 1): LIR has no sub-register insert. The pass needs `setcc` to write the low byte of a wider zeroed value: model it as the existing partial-write form the backend already uses for `setl al` into a ABCD register (lanes.rs / bytes.rs), tied to the zero register. If that is not expressible, the rule is a DEVIATE with the same output as the pin (`xor; setcc` after allocation by a peephole rule with the same flags-def condition) and the exit stated.
Tests: fail-first on `f` and `g` above (asm: `xor` precedes the `cmp`), the refusal when the flags def reads EFLAGS (`adc`), x86-32 ABCD constraint, an `setcc` whose zext is absent.
Evidence to take: changed code in 41 (-O2) and 40 (-Os) of 77 IRs per the ablation; objsweep, rows, QCport, compile Ir in the PR.

## 54 X86 EFLAGS copy lowering (land 11-04)
Pin: [X86FlagsCopyLowering.cpp](https://github.com/llvm/llvm-project/blob/d1106deb71cc81016406a1917d0508d2df296266/llvm/lib/Target/X86/X86FlagsCopyLowering.cpp) `runOnMachineFunction`: find `COPY` of EFLAGS into a vreg, then each flag-using instruction after it is rewritten to test a saved byte (`SETcc` of the needed condition into a GR8 right after the def, `TEST8rr`/`ADD8ri` to restore, `ADC`/`SBB`/`CMOV`/`SETcc`/`JCC` uses rewritten), because flags cannot be live across a flags-clobbering instruction in the register allocator.
Ours: no EFLAGS copy exists in LIR; flag liveness is a lane per instruction (liveness.rs, stepflags.rs) and a flag-clobbering instruction between a def and its use is refused by the peephole / scheduler. Changed code in 2 of 77 IRs (-O2 and -Os). Step 1 (inventory, 11-03): find every LIR place that holds flags across another instruction (x87 `fnstsw; sahf` after `fcom`, `adc` chains in `lower_int64`, `sbb` from compares, branch-on-saved-compare in `booleans.rs`) and list which of them the pin would copy. The translation is then a `LIRTransform` on exactly those; if the inventory is empty on the corpus the pass lands as a translation that does nothing and its tests use hand-made LIR (the pin's own `.mir` tests under test/CodeGen/X86/flags-copy-lowering*.mir are the oracle).

## 98 X86 Byte/Word Instruction Fixup (land 11-04)
Pin: [X86FixupBWInsts.cpp](https://github.com/llvm/llvm-project/blob/d1106deb71cc81016406a1917d0508d2df296266/llvm/lib/Target/X86/X86FixupBWInsts.cpp#L165) `runOnMachineFunction` -> `processBasicBlock` (L434), after allocation: a byte or word load/copy/extend whose 32-bit super-register is dead after it becomes the 32-bit form (`MOV8rm` -> `MOVZX32rm8`, `MOV16rm` -> `MOVZX32rm16`, `MOV8rr`/`MOV16rr` -> `MOV32rr` when the super register is dead, `MOVSX16rr8` -> `MOVSX32rr8` ...) by `tryReplaceLoad` (L285), `tryReplaceCopy` (L316), `tryReplaceExtend` (L353), `tryReplaceInstr` (L388); `OptForSize` (L455) gates the `MOV16rr` -> `MOV32rr` size rule. The translation replaces both with the pin's pass over the allocated LIR, keeping `narrowed_moves` only for what the pin does not do (stated per rule). Step 1 (11-03): diff the two on the corpus (which instructions each rewrites) so the PR states what moves.
Tests: one fail-first LIR/asm test per `tryReplace*` arm and per refusal (super register live; destination in a source; OptForSize).
Evidence: changed code in 63 (-O2) and 62 (-Os) of 77 IRs; objsweep, rows, QCport, compile Ir.
